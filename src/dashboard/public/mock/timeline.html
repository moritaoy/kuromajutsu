表示の規則（案）

  • 1 フェーズ = 1 行。畳んだ行のバーは手順ごとの区切り（色は職種）、ゲート（斜線 黄）、人間レビュー待ち（斜線 青）、修正フェーズ（斜線 橙）を 1 本に収める。
  • 展開すると 手順の行 → その手順を担当した Agent の行。Agent の行は 1 Agent 1 行（並列は縦に並ぶ）。ラベルに職種・ツール回数・所要時間、ホバーでモデル・編集ファイル数・トークン。
  • 自動規則: 実行中 / レビュー待ちのフェーズは展開、完了・未着手は畳む。手動で開閉したフェーズはその状態を優先（フェーズの状態が変わるまで）。計画表の選択（カードをクリック）と連動して該当フェーズを開く。
  • 実行中のバーは右端の「now」線まで伸び、縞が流れる。未着手フェーズは点線の空行（時刻の見当は出さない）。
  • マーカー: ◆ ゲート（合格 緑 / 不合格 赤 / 実行中 黄）、👤 人間レビュー待ち（区間）、↻ 差し戻し、⚠ イレギュラー、⟲ リプラン。
  • 高さ: 畳んだ行 24px、手順 18px、Agent 15px。本体は最大 260px（実行中は 200px）でスクロール。軸は上に固定。
  • 実行後（完了レポート）: 同じ部品を「経過」の中に置き、全フェーズを畳んだ状態 + 合計行（所要 / Agent 数 / ツール回数 / トークン）で出す。
